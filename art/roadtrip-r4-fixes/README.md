All Accepted images in ROAD_TRIP.md remain in v3, unchanged. No game files or Godot import settings were modified. These five files retain the existing names so they can replace their v3 counterparts after review.

Open index.html for before/after inspection. verification.json records the pixel and size checks. PROMPTS.md records built-in image generation and the deterministic fix methods. fix-details.json records crop regions, fold positions and paint masks.

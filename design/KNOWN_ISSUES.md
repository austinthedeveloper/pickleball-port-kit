# Known Issues

Defects of the Godot port: open ones and accepted minors first, then the
fixed ones worth remembering, then the SNES game's (from its M3 candidate,
`M3-QA-06`, on), kept for reference since the port started from them. Add a
row for each new defect with the next number; when one is fixed, mark it
Resolved, say how (the branch and the test), and move it down.

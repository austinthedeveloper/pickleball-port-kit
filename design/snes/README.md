# SNES-era docs

Docs from the SNES game's repo (`../pickleball`) that describe the ROM, its
build or its 1994 manual, kept for reference and lore. They're not the
port's: the port's player guide is `game/README.md`, its plan
`design/PORT_ROADMAP.md`, its ideas still open `design/GOOFY_IDEAS.md`.

| File | What it is |
|---|---|
| `PLAYER_GUIDE.md` | The SNES 0.18.1 player guide (a few port notes were added later). |
| `MANUAL.md` | Draft text for the 1994 printed manual (SNES buttons, the Multitap). |
| `IDEAS.md` | The SNES repo's idea list; nearly every entry has shipped, each with its ADR. |
| `05_TEST_PLAN.md` | The SNES test levels and hardware checks (`make check`). |
| `04_INPUT_MULTITAP_PLAN.md` | The SNES Multitap plan (the port's four players: PORT-16). |
| `REFACTOR_PLAN.md` | The 816-tcc refactors R0-R25 (SNES frame budget). |

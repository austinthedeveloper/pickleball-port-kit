# About this project

*Pickleball '94* is a real game you can play: a Super Nintendo cartridge
and this remaster. Both were made in 2026.

The story around them is made up. There was no 1993 release, no
publisher, no holiday ad, no magazine review, and no *Pickleball '95*.
That history is part of the fun, told in the game's lore and its
artifacts (the box, the manual, the ads). It is not meant to fool anyone,
and this note goes with every public release so that it doesn't.

The game uses no real brands, outlets or people. *Pickleball* itself is
real: it was invented in 1965 on Bainbridge Island, Washington.

Not affiliated with or endorsed by Nintendo. Super Nintendo, SNES, Super
Famicom and Super Multitap are named only to describe the hardware the
original cartridge was made for.
